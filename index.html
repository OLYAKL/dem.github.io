🔐 RSA Шифрование: Практика

Параметры ключей:

  • Открытый ключ: (e, n) = (5, 21)
  • Закрытый ключ: (d, n) = (5, 21)

Процесс шифрования слова "привет":

Исходное слово: привет
Числовое представление: [17, 18, 10, 3, 6, 20]
Открытый ключ (e, n): (5, 21)
Шифртекст: [5, 9, 19, 12, 6, 20]

Процесс расшифровки:

Шифртекст: [5, 9, 19, 12, 6, 20]
Числа после расшифровки: [17, 18, 10, 3, 6, 20]
Расшифрованное сообщение: привет ✅

* Примечание: в реальном RSA число n было бы огромным (например, 152348...), здесь приведен учебный пример.

📊 Прогнозирование успеваемости

Пример кода для прогноза баллов студента на основе часов подготовки:

import pandas as pd

# Один прогноз
new_student = pd.DataFrame({'Часы': [5]})
prediction = regressor.predict(new_student)
print(f"Студент занимался 5 часов")
print(f"Прогноз баллов: {prediction[0]:.2f}")

# Группа студентов
students = pd.DataFrame({'Часы': [1, 3, 5, 7, 10]})
predictions = regressor.predict(students)

results = pd.DataFrame({
    'Часы подготовки': students['Часы'],
    'Прогноз баллов': predictions
})
print(results)
